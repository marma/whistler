Shared data, mounted in VM sessions at /shared/<name> over S3. A dataset is either a Whistler-managed volume — storage Whistler creates and serves — or an external S3 bucket, reached through a proxy that holds the bucket credential. Either way sessions only ever see a Whistler-run endpoint, fenced so only granted users can reach it. Grant a dataset in the access matrix of the Groups or user editors.

Datasets, not filesystems. S3 through FUSE has no byte-range locking, no atomic rename and no hardlinks, and concurrent writers resolve as a silent last-writer-wins. Good for read-mostly data — corpora, model weights, media. Not a place to put a database, a git repo or a home directory. Prefer read-only unless one session at a time owns the writes. Mounts are VM-only; container sessions see no dataset.
