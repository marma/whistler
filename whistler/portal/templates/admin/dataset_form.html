How changes apply

Access changes take effect at once: saving re-fences this dataset's proxies, so revoking write access does not wait for anyone's session to restart. The mount itself is set up by cloud-init at boot, so a changed bucket, endpoint or prefix reaches a running session only when it next starts.

A managed dataset starts out empty. To fill it, grant yourself write access to it in a zone and copy data in from a VM session there.
